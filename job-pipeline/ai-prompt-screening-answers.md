# AI prompt — answer any screening question in Eric's voice

**How to use:** paste the block below into Claude (or any AI), then paste the job description
and the screening question(s). It returns answers in Eric's real voice, using only his true
facts. Works for LinkedIn/Greenhouse/Ashby/Lever application questions, "why you?" boxes,
and short-answer supplements.

---

## Quick tips
- Always paste the **actual job description** with the question — the answers get far better
  when the AI can mirror their language.
- For a "record a short video answer" prompt, ask the AI to output a **:30–:60 teleprompter
  script** instead of a written answer (say so in your request).
- Sanity-check every number before you submit — the prompt is locked to Eric's real facts,
  but you're the final gate on accuracy.
