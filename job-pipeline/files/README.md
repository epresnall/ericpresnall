# Your uploadable resume files — which one to use

All are the **same true facts**, ATS-safe (single column, standard headings). The only
difference is which keywords/results are surfaced first — that's the per-job tailoring that
research shows gets ~6x more interviews. Pick the one that matches the role, or start from the
master.

| File | Use it when the role is about… |
|---|---|
| **Eric-Presnall-On-Camera-Spokesperson.docx** | **Master / default** — general spokesperson, host, presenter, anything mixed. |
| **Eric-Presnall-Sales-Funnel-Ads-UGC.docx** | Ads, UGC, VSLs, paid social, DTC performance creative. |
| **Eric-Presnall-Content-YouTube-Host.docx** | YouTube, brand content, audience growth, long-form. |
| **Eric-Presnall-Product-Training-Demos.docx** | Product demos, onboarding, e-learning, explainer (SaaS/tech). |
| **Eric-Presnall-Live-Shopping-Host.docx** | Live shopping, livestream selling, real-time brand hosting. |
| **Eric-Presnall-resume.txt** | Paste-in "enter your resume" boxes on application forms. |

**How to use:**
1. Pick the variant matching the role's bucket.
2. Open it, and in ~2 minutes edit the summary's first line to echo the posting's exact title
   (e.g. "On-Camera Host" if that's their word) — see `../RESUME-STRATEGY.md` §2.
3. Upload the .docx. If a posting demands PDF, open in Word/Google Docs → Save as PDF (one click).

before you send it.**
