# Interview Guide v2 — All Tasks, All Questions

Answer in any session (web or desktop), any order, in chunks — reference the
question numbers (e.g. "1.4: full sweep"). Write "skip" to skip. Whichever
session receives answers files them here, follows up, distills decisions into
the plan doc, and pushes. Section 0 shapes everything — answer it early.
